# МедЭксперт — MVP

Next.js 16, Payload CMS 3, PostgreSQL. Один проект: публичный сайт и админка `/admin`.

## Реализовано

- Врачи: фото, специальность, биография, образование, города, места приёма, публикация и история изменений.
- Отдельный ручной ID врача в МИС; хранится строкой с начальными нулями, скрыт из публичного API. Интеграция расписания отложена.
- Документы врачей добавляются прямо из карточки врача. Опубликованные JPEG/PNG показываются в карусели с увеличением, PDF доступны для скачивания. Скрытие врача закрывает его файлы.
- Услуга и цены редактируются в одной карточке: название, раздел, выбранные города, цена и список филиалов каждого города. Прежние записи цен сохранены и подставляются автоматически. Региональный редактор видит и меняет только свои города; название и общий раздел изменяет администратор. Сохранение услуги и цен выполняется в одной транзакции.
- Прайс: поиск, собственные селекты, подсветка доступных центров при наведении; последняя выбранная услуга остаётся справа. На телефоне центры открываются нажатием на строку.
- Разделы появляются в городе автоматически по доступным опубликованным услугам; пустые разделы скрываются. Ручной привязки разделов к городам нет. Для показа услуги нужен опубликованный филиал — редактор цен отмечает филиалы-черновики и объясняет, почему услуга не появится на сайте.
- Локальный Roboto с кириллицей; широкий первый экран; три оригинальных видео компании; документы футера в модалках.
- Отзывы: публичная форма → модерация → публикация/отклонение; отдельный официальный ответ с независимым флагом публикации. Контакты, заметки и согласие не публикуются.
- Акции по городам со сроками; филиалы; редактируемые текстовые страницы.
- Администратор сети и редактор с назначенными городами и разделами. Общую карточку врача нескольких городов может изменить только сотрудник с доступом ко всем этим городам.
- Старые основные адреса и параметры: `/price`, `/specialists#doc_ID`, `/about_services?service=mrt`, `/med_points?center=19`, `/news.php#80`. Для врачей добавлены отдельные страницы; старый якорь открывает соответствующую карточку.

## Локальный запуск

Нужен Node.js **24.22.1 или новее**. PostgreSQL можно использовать свой или запустить отдельный локальный сервер из npm-пакета `embedded-postgres`.

```sh
npm ci
npm run setup:local
npm run db:local
```

Оставьте PostgreSQL запущенным. В другом терминале:

```sh
npm run seed
npm run dev
```

Сайт: `http://127.0.0.1:3100`. Админка: `http://127.0.0.1:3100/admin`.

`setup:local` создаёт случайные секреты в `.env.local` и случайные пароли в `.local/bootstrap.json`. Эти файлы исключены из Git. Генератор не перезаписывает существующие настройки. Данные PostgreSQL сохраняются в `.local/postgres`; сервер слушает только `127.0.0.1:55432`. На Windows запуск PostgreSQL из ограниченной среды может требовать запуска вне её песочницы; менять системные службы не нужно.

Seed предназначен для демонстрации: два города, три филиала, семь врачей, прайс, акции и тестовые отзывы. Он не является переносом всей базы действующего сайта. Цены Белгорода в демо специально отличаются для проверки городской логики и требуют замены на утверждённый прайс. Seed запрещён в production и сохраняет существующие данные при повторном запуске.

## Проверки

Проверены создание услуги через админку с двумя ценами и выбором филиалов, сохранение после перезагрузки, карусель сканов, модалки документов, переключение города и экранные размеры 390, 1509 и 2560 px. Тестовые записи создаются с уникальными идентификаторами и удаляются после проверки.

```sh
npm run typecheck
npm test
npm run test:integration
npm run verify:migrations
npm run build
```

Для HTTP-тестов должен работать `npm run dev` на порту 3100. Интеграционные тесты создают собственные временные записи и удаляют только их. Проверка миграции создаёт случайно названную отдельную базу на локальном PostgreSQL и удаляет только эту базу после проверки. Для неё нужны локальные права CREATE DATABASE.

Проверяются ограничения городов и модулей, запрет повышения прав, скрытие ID из МИС, публикация файлов, подмена типа файла, CSRF, повторная отправка, отклонение и публикация отзыва/ответа, старые URL и защитные заголовки.

## Рабочее размещение

Приложению нужны PostgreSQL и постоянный каталог файлов вне сборки. Настройте переменные из `.env.example`; для файлов задайте абсолютный `STORAGE_DIR`. При TLS для базы задайте `DATABASE_CA_FILE`; проверка сертификата не отключается.

Перед первым запуском:

```sh
npm ci
npm run migrate
npm run build
npm start
```

Первый администратор создаётся только локальной командой `npm run admin:create`: она принимает JSON с `email`, `password`, `name` через stdin. Используйте ввод пароля без отображения или менеджер секретов; не помещайте пароль в аргументы команды/историю shell. Команда отказывается работать, если сотрудник уже существует. Публичная регистрация закрыта. Демо-учётные записи и `.env.local` в рабочую среду не переносить.

`npm start` запускает standalone-сборку, копирует только публичные ресурсы и использует постоянный `STORAGE_DIR`. По умолчанию слушает `127.0.0.1:3100`; `PORT`/`HOSTNAME` можно задать для выбранной инфраструктуры.

Размещать за HTTPS reverse proxy с ограничениями размера тела и частоты запросов, резервировать PostgreSQL вместе с `STORAGE_DIR`, проверить восстановление. `TRUST_PROXY=true` включать только если proxy заменяет `X-Real-IP` и закрыт прямой доступ к приложению. До приёмки оставить `ALLOW_INDEXING=false`; при включении индексации пересобрать сайт, чтобы обновились robots.txt и sitemap.xml. Восстановление пароля по email отключено до настройки почтового адаптера; администратор может менять пароли сотрудников в админке.

Подробности защиты и известные ограничения: [SECURITY.md](SECURITY.md).

## Материалы

Логотип, портреты и фотографии помещений взяты с публичного `med-exp.ru` для адресного предложения этой компании. Портреты для seed находятся вне публичного каталога: `seed-assets/doctors`. Перед внешним использованием нужно согласование компании. Биографии и документы заполняются клиникой; фиктивные дипломы и медицинские утверждения не создавались. Тестовые отзывы явно отмечены как демонстрационные.
